# 简历能力证据重构

把「做过什么」整理成「能解决什么问题」的简历。

这是一个可安装的 Agent Skill。根据原简历与目标岗位要求筛选真实经历，突出个人作用、关键行动和实际结果；信息笼统时主动追问，允许跳过后继续生成。

## 技能目录

技能位于 [skills/tailor-evidence-resume](skills/tailor-evidence-resume)，包含 SKILL.md 入口与 references/examples.md 示例文件。安装时请使用这一整个目录，避免只取入口而遗漏示例。

采用通用 SKILL.md 与 YAML frontmatter，不包含平台专属连接器、产品白名单、私有路径、API密钥或外部服务依赖。

## 使用

安装后描述任务即可，例如：

> 根据这份简历和目标岗位要求，帮我重写简历。突出我解决的问题和个人贡献，缺失信息请主动追问。

适合已有工作、实习或项目经历，希望根据具体岗位改写简历的人。经历较少时可用真实课程或志愿项目；没有个人素材时只生成空白框架。

## 追问与跳过

- 每次一个重点，默认最多三轮；资料足够直接生成。
- 「跳过这题」：不再追问当前事实，可继续其他重要问题。
- 「直接生成」「全部跳过」「先给一版」：立即停止追问，基于现有事实出稿。
- 没有数字也能写真实行动、交付物与可观察变化，不编造成果。

## 输出与事实约束

先给完整简历，再简述调整和证据缺口。按「问题或场景—个人作用—行动—结果」组织，不强求每条写满四项；待补内容放在简历正文之外。

保留真实公司、职位、日期及贡献边界，不把团队业绩写成个人业绩，不将JD要求变成用户已经掌握的技能。素材不足时保留准确的任务描述。

无需向本仓库提交个人简历。本仓库仅分发技能文件，不提供简历收集或存储服务；运行时资料处理由使用的AI平台决定。技能不保证面试、录用或自动筛选结果。
